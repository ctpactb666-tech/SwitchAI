# Neon UI — что изменено

Новые файлы:
- ui/catalog/AssistantCatalog.kt — список всех ассистентов для нового UI (имя, компания, иконка, плитка)
- ui/catalog/AssistantUiPreferences.kt — настройки конкретного ассистента (голосовой режим, приоритет, скрытие…)
- ui/NeonViews.kt — общие помощники для верхней панели и строк с переключателями
- wakeword/WakeWordState.kt — реальное состояние фонового прослушивания (для «Активно»)
- wakeword/WakeWordSettings.kt — ключи настроек голосовой активации, запуск/остановка сервиса
- wakeword/WakeFeedback.kt — звук и вибрация при срабатывании
- wakeword/WakeLaunchNotifier.kt — уведомление «Разговор с …» (и запасной запуск по нажатию)
- res/values/strings_neon_ui.xml — все тексты нового интерфейса

Исправления логики:
- Без обученного голоса фраза теперь запускает ассистента (раньше запуск всегда блокировался)
- Совпадение фразы: по целым словам внутри сказанного; «Точное совпадение» — только целиком
- Несколько вариантов фразы через «;»
- Чувствительность реально меняет порог проверки голоса
- Защита от двойного запуска (частичный + финальный результат распознавания)
- colors.xml: исправлена сломанная первая строка
- Пункт «Голосовая активация» в Настройках ведёт на новый экран
